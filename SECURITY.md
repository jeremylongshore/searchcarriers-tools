# Security policy

Do not open public issues for suspected vulnerabilities, exposed credentials,
or leaked carrier datasets. Use GitHub's private vulnerability reporting for
this repository. Include the affected version, reproduction steps, impact, and
any suggested mitigation. Remove tokens and personal or licensed data from all
attachments.

Supported security fixes target the latest release on the default branch.
SearchCarriers account, billing, or upstream service incidents should be sent
to SearchCarriers through its official support channel.
