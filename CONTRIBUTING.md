# Contributing

Thank you for improving SearchCarriers Tools.

1. Open an issue for substantial behavior or API-contract changes.
2. Create a focused branch and keep commits reviewable.
3. Use only synthetic test data. Do not include API responses, customer data,
   personal information, or credentials in code, fixtures, logs, or issues.
4. Read `API-DISCOVERY.md` before changing routes or parameters. Add a contract
   test that asserts the outgoing route and parameter names.
5. Run the repository validation commands from `CLAUDE.md`.

By submitting a contribution, you agree that it is licensed under Apache-2.0.
